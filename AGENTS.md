# multi-model-cli

Обвязка, через которую Claude Code отдаёт работу моделям других вендоров: Codex (OpenAI),
Antigravity `agy` (Gemini, а также Claude и GPT-OSS в квоте Google), Grok (xAI).
Скрытые скрипты `scripts/ask-*.sh`, видимый режим в agterm `scripts/delegate-tab.sh`,
скиллы `delegate` и `second-opinion`, субагенты в `agents/`. Устанавливается симлинками
в `~/.claude` (`install.sh`).

## Правила репозитория 

1. Репозиторий **публичный** (решение владельца). Сюда не попадают секреты, `.env`,
   данные, логи, адреса серверов, имена людей и внутренние детали агентства. Всё
   личное и серверное — в закрытых репозиториях и vault.
2. Сначала план, потом код. Планы не удаляются: `plan/vN-YYYY-MM-DD.md`, новая версия
   начинается с «Что изменилось относительно vN и почему». Этапы — `plan/tasks/`,
   готовые уезжают в `plan/tasks/completed/`. Индекс — `plan/README.md`. Отклонились от
   плана — сначала новая версия плана, потом код.
3. Этот файл несёт правила с собой; `CLAUDE.md` рядом содержит одну строку `@AGENTS.md`.
